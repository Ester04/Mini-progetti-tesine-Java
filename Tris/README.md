# Tris
Questo è un semplice progetto in Java costituito da 4 file:
- Il principale è `TrisLauncher.java`; eseguendolo si apre un menù con tre opzioni di gioco differenti per Tris (la versione classica, il "Super Tris" e il Tris a tre giocatori). Accanto a ogni modalità di gioco è presente un pulsante cliccabile che raffigura un punto interrogativo ("?"), dal quale possono essere lette le diverse regole di gioco.
- Gli altri tre file in Java, come si può intuire, sono le tre possibili versioni di gioco.
